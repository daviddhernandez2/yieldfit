# Yield Fit — cliente

Frontend de Yield Fit: React 19 + Vite 8.

Instalación, variables de entorno, arranque en local y scripts: ver el
[README principal](../README.md). La documentación técnica está en [docs/](../docs/README.md).

```bash
npm install
cp .env.example .env   # VITE_API_URL=http://localhost:3000/api
npm run dev            # http://localhost:5173
```
